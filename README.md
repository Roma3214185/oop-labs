# OOP labs

| Lab | Topic | Folder |
|-----|-------|--------|
| 1 | OOP: chef, vegetable hierarchy, salad | [lab1](lab1) |
| 2 | XML / XSD / SAX, DOM, StAX / XSLT: medicines | [lab2](lab2) |
| 3 | Android (Java): maze game, Timber logging, i18n (en/uk) | [lab3](lab3) |
| 4 | Swing GUI, CRUD: contact book | [lab4](lab4) |

Requirements: JDK 21+, Maven 3.9+ (lab1, lab2, lab4); Android SDK 35 (lab3).

```bash
cd lab1 && mvn clean verify
cd lab2 && mvn clean verify
cd lab3 && ./gradlew test assembleDebug
cd lab4 && mvn clean verify
```

Code coverage reports are generated by JaCoCo into
`target/site/jacoco/index.html` of lab1, lab2 and lab4.

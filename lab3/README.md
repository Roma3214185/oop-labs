# Лабораторна робота 3 — гра «Лабіринт» (Android, Java)

Android-застосунок: потрібно вивести червону кульку з лабіринту до
зеленого виходу. Кожна нова гра — новий випадковий лабіринт.
Логування — Timber, інтерфейс англійською та українською з перемикачем
мови прямо в грі.

## Як це працює

1. **Старт.** `MazeApplication.onCreate()` налаштовує логер (див. нижче).
2. **Екран.** `MainActivity` бере `GameViewModel`; якщо гри ще немає —
   `MazeGenerator` генерує лабіринт 21×21, створюється `Game`.
   `MazeView` малює поле, над ним — кількість кроків.
3. **Хід.** Кнопка ↑ ← → ↓ → `viewModel.move(direction)` →
   `game.move(direction)` перевіряє крок і повертає `MoveResult`:
   - `MOVED` — гравець перейшов, кроків +1, поле перемальовується;
   - `BLOCKED` — стіна або край поля, гравець на місці, статус «Там стіна!»;
   - `ESCAPED` — дійшли до виходу, діалог перемоги з кнопкою «Нова гра»;
   - `FINISHED` — гра вже закінчена, хід ігнорується.
4. **Меню.** «Нова гра» — новий лабіринт. «Мова» — як у системі /
   English / Українська.
5. **Зміна мови чи поворот екрана** перестворюють Activity, але гра
   живе у `GameViewModel`, тому лабіринт і позиція зберігаються.

## Структура

| Клас | Призначення |
|------|-------------|
| `model.Direction` | enum напрямків: зсув рядка й колонки |
| `model.Position` | record (рядок, колонка), `next(direction)` |
| `model.Maze` | сітка стін, старт, вихід; `isFree()` — у межах поля і не стіна |
| `model.MazeGenerator` | випадковий лабіринт пошуком у глибину |
| `model.Game` | гравець, кількість кроків, `move()` — валідація кроку |
| `model.MoveResult` | результат ходу |
| `MazeApplication` | налаштування логера |
| `GameViewModel` | тримає гру між перествореннями Activity, логує ходи |
| `MazeView` | малює лабіринт на `Canvas` |
| `MainActivity` | кнопки, статус, діалог перемоги, меню мови |

Пакет `model` — чиста Java без Android, тому вся логіка гри перевіряється
звичайними JUnit-тестами без емулятора.

### Генерація лабіринту

Клітинки стоять на непарних рядках і колонках, між ними стіни. Алгоритм
(recursive backtracker) іде від старту до випадкової невідвіданої сусідньої
клітинки, прибирає стіну між ними, а в глухому куті повертається назад
стеком. Кожна клітинка відвідується рівно раз, тому від старту можна
дійти до будь-якої клітинки й до виходу.

## Логування (Timber)

Налаштування в `MazeApplication`:
- **debug-збірка** — `Timber.DebugTree`: усе в Logcat, тег = ім'я класу;
- **release-збірка** — `ReleaseTree`: лише `WARN` і `ERROR`.

| Подія | Рівень |
|-------|--------|
| запуск застосунку, нова гра (розмір, seed), перемога, зміна мови | INFO |
| кожен хід, удар у стіну, створення Activity | DEBUG |
| хід після завершення гри | WARN |

Дивитися: вкладка Logcat в IDE або `adb logcat`, фільтр `ua.maze`.

## Багатомовність (i18n)

- Жодного тексту в коді чи розмітці — тільки `@string/...`.
- `res/values/strings.xml` — англійська (за замовчуванням),
  `res/values-uk/strings.xml` — українська.
- Кількість кроків через `plurals` (`getQuantityString`): в українській
  чотири форми — 1 крок, 2 кроки, 5 кроків, 1,5 кроку.
- Перемикач мови в меню: `AppCompatDelegate.setApplicationLocales(...)`.
  На Android 12 і старших вибір зберігається (`autoStoreLocales` у
  маніфесті), на Android 13+ мову можна вибрати й у системних
  налаштуваннях застосунку (`res/xml/locales_config.xml`).
- Щоб додати мову, достатньо створити `values-xx/strings.xml`, додати
  її в `locales_config.xml` і пункт у меню.

## Запуск

Потрібен Android SDK 35 (шлях у `local.properties` або змінній
`ANDROID_HOME`). Проєкт відкривається в Android Studio / IntelliJ IDEA.

```bash
./gradlew assembleDebug   # app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug    # встановити на підключений пристрій / емулятор
```

## Тести

```bash
./gradlew test   # JUnit 5, звіт: app/build/reports/tests/testDebugUnitTest/index.html
./gradlew lint   # перевірка Android lint, зокрема що всі рядки перекладені
```
